## Create a reel with a local background

Pexels is not required. Run the app, tap **اختر فيديو الخلفية من الجهاز**, and
choose a video from the device. The selected video is previewed and used as the
reel background. The ayah audio is still downloaded from the Quran service, so
an internet connection is required to load the ayah and export the reel.
